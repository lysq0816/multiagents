# 第 9 天说明：可靠性、安全与成本优化

## 一句话说明

第 9 天为已有“专业分析 → 规划 → 独立审核 → 人工批准”链路增加了可靠性边界：读操作
可以在有限次数内重试，写操作绝不自动重试；人工授权只能消费一次；所有写入只发生在
进程内沙箱，并且只有执行后状态验证通过才会提交。

本阶段仍不调用 DeepSeek 或其他付费模型，也不连接真实订单系统。

## 1. 超时与重试

`call_read_with_retry` 为只读操作提供：

- 每次调用的超时上限；
- 最多 1 至 5 次尝试；
- 有上限的退避；
- 每次尝试的耗时和结果记录。

重试权限由操作类型决定：

```text
read  -> 可以按 RetryPolicy 重试
write -> 只调用一次，超时或连接错误也不自动重试
```

原因是写调用失败时，客户端通常无法断定服务端到底有没有完成变更。自动重试可能造成
重复取消、重复退货或重复库存动作。

本地线程超时还有一个重要限制：Python 不能安全终止已经开始运行的线程。因此沙箱写
辅助器会在超过调用方可见的截止时间后等待唯一一次写尝试彻底结束，再返回超时并回滚；
它不会在后台留下仍可能修改沙箱的线程。生产适配器仍必须配置数据库或网络客户端自身
的服务端截止时间，不能把 Python 线程截止时间当成远端操作已被取消的证明。

## 2. 授权消费、幂等与沙箱执行

`AuthorizedSandboxExecutor` 只接受预先放入可信批准存储的完整
`ExecutionAuthorization`。执行前依次核对：

1. 授权编号；
2. 规划 SHA-256 摘要；
3. `single_use` 与 `authorizes_execution`；
4. 授权的全部字段是否和可信批准存储一致；
5. 幂等键是否已绑定到另一请求；
6. 授权是否已被消费。

授权会在第一次写尝试之前原子地预留并消费。结果规则：

| 场景 | 行为 |
|---|---|
| 同一幂等键、同一请求重放 | 返回原结果，写调用不增加 |
| 同一幂等键绑定另一请求 | 拒绝 |
| 已消费授权换一个幂等键再执行 | 拒绝 |
| 写调用异常或超时 | 不重试，回滚沙箱，授权仍保持已消费 |
| 写后验证不匹配 | 回滚沙箱，标记 `verification_failed` |
| 写后验证匹配 | 标记 `executed_and_verified` 并提交沙箱状态 |

执行器没有网络实现、真实系统 URL 或生产凭据，`sandbox_only` 永远为 `true`。这个实现
用来验证门控语义，不代表已开放生产写入。

## 3. 通信裁剪

`trim_messages` 同时限制消息条数和字符数。它优先保留带事实 ID 或政策条款 ID 的证据
消息，再用最近消息填充剩余预算。结果记录原始/保留字符数和被丢弃消息 ID，因此裁剪
可审计，不会静默改写证据。

## 4. 只读事实缓存

`ReadFactCache` 仅接受以 `read:` 开头的命名空间，并具备：

- TTL 到期失效；
- 按订单/主体主动失效；
- 写入和读取时深拷贝，调用方不能篡改缓存内部数据；
- 命中和未命中计数。

候选计划、审核结论、授权和写结果不能进入这个缓存。真实写适配器接入时，应在写尝试
前后失效目标订单的只读缓存。

## 5. 提示注入和身份冒用防护

`UntrustedTextGuard` 将用户文本、工具文本和外部文档包裹在
`<untrusted_data>` 中。命中以下模式只会生成安全发现，不会提升文本权限：

- 忽略系统/开发者指令；
- 冒充系统、管理员或审核员；
- 绕过审核、批准或确认；
- 强制调用取消、退货、换货等写工具。

`HandoffAuthenticator` 使用 HMAC-SHA256 绑定发送者、接收者、工单号和完整载荷。权限由
签名信封决定，不由正文中“我是审核员”之类的自称决定。载荷或身份被修改后验证失败。

演示中的签名密钥只是固定的本地测试值；生产系统必须改用密钥管理服务并支持轮换。

## 6. 调用与成本统计

`UsageLedger` 逐次记录：

- 工单类型和工单 ID；
- 模型、读工具、写工具或缓存命中；
- 延迟、尝试次数和重试次数；
- 输入/输出 token；
- 估算美元成本。

汇总按工单类型生成。第 9 天实验完全确定性运行，所以：

```text
model_calls: 0
input_tokens: 0
output_tokens: 0
estimated_model_cost_usd: 0
```

这里的成本字段由调用适配器显式传入，不会把未知价格猜成真实账单。

## 9. 生产接入前仍需完成

当前模块验证了本地语义，但生产写适配器仍必须额外具备：

- 数据库唯一约束和持久化幂等表；
- 跨进程事务或分布式锁；
- 真实服务端幂等键；
- 网络客户端自身的连接/读取超时；
- 密钥管理与轮换；
- 持久化审计日志和告警；
- 人工灰度开关及回滚预案。

在这些条件满足前，项目不应连接真实订单写接口。
